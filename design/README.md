# Интерфейсные референсы

Три отдельных варианта были сгенерированы перед реализацией нативного интерфейса. В них использованы светлые поверхности, компактные разделители, синяя основная кнопка и зелёный индикатор подключения — визуальные решения, близкие к Docker Desktop для macOS.

- `references/01-database-history.png` — широкая история снимков и метрики выбранной базы. Подходит для основного экрана, но исходный макет показывает несуществующий список баз и число таблиц.
- `references/02-resource-list.png` — плотная панель ресурсов с отдельной узкой навигацией. В ней слишком много навигационных уровней для приложения с подключением и одной историей снимков.
- `references/03-empty-state.png` — ясно показывает подключение, действия и пустое состояние, но отдельная информационная колонка занимает заметную часть окна.

В код перенесена структура третьего варианта: список подключений слева, карточка выбранной базы вверху, история снимков в центре и спокойная поясняющая панель справа. На узком окне поясняющая панель перестраивается ниже истории. Макеты адаптированы к реальным возможностям Rust-бэкенда: экран показывает только доступные сервер, порт, пользователя, версию и размер базы; фиктивные таблицы, схемы, заметки и лимиты хранилища не добавлены.
